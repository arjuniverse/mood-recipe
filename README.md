## 🚀 Installation

```bash
# Clone repository
git clone https://github.com/your-username/MoodMeal-AI.git

# Open project folder
cd MoodMeal-AI

# Install dependencies
npm install

# Start frontend
npm start

# Start backend
node server.js
```
