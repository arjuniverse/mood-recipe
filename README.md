# 🍽️ MoodMeal AI
**MoodMeal AI** is an AI-powered mood-based recipe recommendation platform that suggests meals based on a user’s emotions, cravings, energy level, and preferences. Using Natural Language Processing (NLP) and Machine Learning, the app analyzes how users feel and recommends personalized recipes, comfort foods, healthy meals, and drinks.

---

## ✨ Features

- 😊 Mood-based recipe recommendations  
- 🧠 AI emotion detection using NLP  
- 🎤 Voice input support for mood analysis  
- 🍜 Personalized meal suggestions  
- 📖 Step-by-step recipe instructions  
- 🔥 Calorie and nutrition information  
- 💾 Save favorite recipes  
- 🌙 Dark mode support  
- ⚡ Smooth modern UI with animations  

---

## 💡 How It Works

1. User enters or speaks their mood  
   - Example: “I’m stressed and tired”  
2. NLP model analyzes the emotion  
3. AI recommends suitable meals  
4. User views recipe details, ingredients, and cooking steps
